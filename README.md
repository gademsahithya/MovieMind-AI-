# 🎥 MovieMind AI

AI-powered movie information extractor built with Streamlit, LangChain, and Mistral AI.

🔗 🔗 [Live Demo](https://svdzbhxp7q4hvfwr9t9sff.streamlit.app/)

---

## ✨ Features

- Extracts structured movie information using AI
- Generates clean JSON output
- Uses LangChain + Mistral AI for intelligent extraction
- Modern Streamlit UI
- Session-based request limiting
- Structured data validation using Pydantic

---

## 🛠️ Tech Stack

- Python
- Streamlit
- LangChain
- Mistral AI
- Pydantic
- dotenv
